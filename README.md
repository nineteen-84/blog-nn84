# 🖋️ Blog NN84: Hub de Conhecimento Nineteen Eighty-Four

O **Blog NN84** é o workspace oficial e central de conteúdo da **Nineteen Eighty-Four**, uma empresa de desenvolvimento web fundada em 2025 por estudantes de Sistemas para Internet do **Senac**. 

Nosso objetivo é documentar, dissertar e simplificar tópicos complexos do ecossistema de programação, servindo tanto como um laboratório técnico para nossa equipe quanto como uma fonte de consulta para a comunidade dev.

---

## 🚀 Sobre a Nineteen Eighty-Four
A empresa nasceu da união de estudantes com o propósito de criar soluções digitais sólidas e criativas. O Blog NN84 reflete nossa cultura de *Continuous Learning* (Aprendizado Contínuo), onde transformamos desafios técnicos de sala de aula e do mercado em artigos e documentações acessíveis.

## 🛠️ Stack Tecnológica (Previsão)
O projeto está sendo construído com foco em performance e SEO:
- **Backend:** Node.js (Fastify/NestJS) & PostgreSQL.
- **Frontend:** React.js / Next.js (para renderização estática e SEO).
- **Design:** Planejado via Figma com foco em experiência do usuário (UX).

## 📋 Documentação de Negócio

### Requisitos Funcionais (RF)
- [ ] O sistema deve permitir que autores publiquem e editem artigos.
- [ ] O usuário deve conseguir filtrar conteúdos por categorias/tags.
- [ ] Deve haver uma área de "Newsletter" para captar leitores interessados.

### Requisitos Não-Funcionais (RNF)
- [ ] **Performance:** O blog deve atingir nota >90 no Lighthouse (SEO e LCP).
- [ ] **Segurança:** Autenticação robusta para os editores do grupo.

### Regras de Negócio (RN)
- [ ] Um artigo só pode ser publicado após revisão de pelo menos dois membros do grupo.
- [ ] Somente usuários com cargo de "Admin" podem excluir comentários.
